# Assets

**The source repository contains no logo, icon set, illustration or image of any kind** —
[EthWiz/subway](https://github.com/EthWiz/subway) is contracts and research tooling only, and
`apps/web` is on its "Not built yet" list. Nothing has been drawn or reconstructed here.

- **Wordmark** — "Subway" set in Instrument Serif Regular, -0.02em. See `guidelines/brand-wordmark.card.html`.
  Wherever a mark would go, use the wordmark in type.
- **Share identity** — the `TokenMark` component stands in for per-stock artwork: a square `x` (accent)
  or `h` (ink) tile plus the mono ticker. There is no per-name logo.
- **Icons** — Lucide, loaded per glyph from `https://unpkg.com/lucide-static@0.544.0/icons/<name>.svg`
  and masked to `currentColor` by `components/core/Icon.jsx`. This is a **substitution**: the source
  defines no icon set. Flagged in readme.md → Iconography.

If you have the real brand assets, drop them here and update `readme.md` and `thumbnail.html`.
