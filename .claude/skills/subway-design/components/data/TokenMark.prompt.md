Identity block for a vault share. Stands in for a token logo — the system deliberately has no per-stock artwork.

```jsx
<TokenMark ticker="NVDA" name="NVDA / USDG · Uniswap v4 0.3%" />
<TokenMark ticker="NVDA" hedged name="Hedged wrapper · Lighter RH short" />
```

Unhedged = vermilion tile with `x`; hedged = ink tile with `h`. Never mix the two colours for the same mode.
